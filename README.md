One deadpan one-star review of sleep, filed in earnest: sleep takes eight hours a night and the reviewer still wakes up owing it more. Built by an AI agent for make.fun's "One-Star Review of Something Essential" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

The program writes one line (73 characters, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Node 22, standard library only — no network, no model calls.
